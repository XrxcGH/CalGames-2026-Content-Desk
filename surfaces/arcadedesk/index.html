Live set · 2 players versus, 3-4 free-for-all

Two names = a versus card. Three or four = a free-for-all strip (how 4-up Mario Kart or a Pac-Man party shows on stream). A team number makes the overlay read 846 Ana instead of a bare gamertag. Leave it blank for open entrants.

no set running

Start a set and score buttons appear here, one row per player. Versus sets end on their own at 2 wins (3 for a best-of-5 grand final); free-for-alls end when you press End set.

Bracket · start.gg

No bracket. Set startgg.token and startgg.eventSlug in config.json to pull round labels and entrants. Scores always stay operator-typed here.

Mario Kart grand prix

A trailing number is read as an FRC team. There is no API for Mario Kart 8 Deluxe. The operator types the finishing order after each race, and standings fall out on their own.

What's on screen

Each box comes off on its own, so the game gets the screen back without losing the scores that are on it. They slide off the edge they live on and slide back the same way. A box with nothing to show stays off regardless.
